# Predicting-Medical-Costs

The goal of this exercise is to build a linear regression model to predict individual
medical costs billed by health insurance for patients in the US ( charges ), based on six
features:


• age : Age of primary beneficiary (integer)

• sex : Insurance contractor sex (female/male)

• bmi : Body mass index (continuous)

• children : Number of children covered by health insurance / Number of dependents
(integer)

• smoker : Whether the patient smokes (yes/no)

• region : The beneficiary’s residential area in the US (northeast, southeast, southwest,
northwest)

The dataset, which was accessed on kaggle (https://www.kaggle.com/datasets/mirichoi0218/insurance/data).
